Sombras en css

CSS tiene dos propiedades principales para sombras: box-shadow: sombra alrededor de la caja del elemento. text-shadow: sombra del texto. La sintaxis de box-shadow es:

  • x / y: mueven la sombra horizontal y verticalmente (admiten negativos).
  • desenfoque (blur): cuanto mayor, más suave es la sombra. 0 da un borde nítido.
  • expansión (spread): agranda o reduce la sombra (opcional).
  • color: normalmente con transparencia (rgba) para un aspecto natural.
  • inset: al inicio, convierte la sombra en interior.

text-shadow funciona igual pero sin expansión ni inset. Para sombras que respeten formas transparentes (como PNG o SVG) existe filter: drop-shadow(). Se pueden poner varias sombras separadas por comas.
