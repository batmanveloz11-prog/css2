Bordes en CSS

La propiedad border dibuja una línea alrededor de un elemento, entre el padding y el margin. Se define con tres valores:

  • border-width: define el grosor del borde.
  • border-style: define el estilo del borde (solid, dotted, dashed, double, groove, ridge, inset, outset, none).
  • border-color: define el color del borde.

Se puede escribir en forma abreviada (border: 2px solid red) o por lado (border-top, border-right, border-bottom, border-left). Con border-radius se redondean las esquinas, y outline dibuja una línea externa que no ocupa espacio en el modelo de caja.
