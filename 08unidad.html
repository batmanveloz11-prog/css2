Grid

Contenido del Grid

CSS Grid es un sistema de maquetación en dos dimensiones: filas y columnas a la vez. Se activa con display: grid en el contenedor. Es ideal para estructuras de página completas y galerías, mientras que Flexbox suele ser mejor para componentes en una sola dirección. Ambos se complementan.

Propiedades del contenedor:

  • grid-template-columns: define las columnas (200px 1fr 1fr, repeat(3, 1fr)).
  • grid-template-rows: define las filas.
  • gap (row-gap, column-gap): espacio entre celdas.
  • grid-template-areas: define la estructura con nombres.
  • justify-items / align-items: alinean el contenido dentro de cada celda.

Propiedades de los elementos:

  • grid-column / grid-row: posición y tamaño en la cuadrícula (grid-column: 1 / 3).
  • justify-self / align-self: alinean el contenido dentro de la celda individual.
