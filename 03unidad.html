Fondos en Css

Las propiedades de fondo permiten decorar el área detrás del contenido de un elemento (contenido, padding y borde). Las principales son:

  • background-color: color sólido de fondo.
  • background-image: imagen o degradado (url(...), linear-gradient(...), radial-gradient(...))
  • background-repeat: define cómo se repite la imagen de fondo.
  • background-position: define la posición inicial de la imagen de fondo.
  • background-attachment: define cómo se comporta el fondo cuando el contenido se desplaza.
  • background-size: define el tamaño de la imagen de fondo.

Todas se pueden combinar en la abreviatura background. Además, se pueden apilar varios fondos separándolos por comas; el primero queda encima.
