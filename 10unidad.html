Como incluir Bootstrap en HTML

¿Qué es Bootstrap?

Bootstrap es un framework de CSS (y JavaScript) que ofrece componentes y clases ya diseñadas: botones, tarjetas, barras de navegación, rejilla responsiva, formularios, modales, etc. Permite construir interfaces rápidamente aplicando clases en el HTML en lugar de escribir CSS desde cero.

Formas de incluir Bootstrap

  1. CDN (la más simple): Se enlaza desde internet con <link> para el CSS y <script> para el JavaScript. Requiere conexión a internet.
  2. Archivos locales: Se descarga desde getbootstrap.com y se enlaza con rutas relativas. Funciona sin internet.
  3. Gestor de paquetes (npm): npm install bootstrap, pensado para proyectos con herramientas de compilación (bundlers).

Requisitos Importantes

  • Declarar <!DOCTYPE html> al inicio del documento.
  • Incluir la metaetiqueta viewport para asegurar el comportamiento responsivo:
    <meta name="viewport" content="width=device-width, initial-scale=1">
  • El archivo CSS se coloca dentro de la etiqueta <head>.
  • El JS (bootstrap.bundle.min.js, que ya incluye Popper) va situado justo antes de cerrar el </body>.
  • El JavaScript solo es necesario para componentes interactivos (menús desplegables, modales, carruseles, navbar colapsable). Para aplicar únicamente estilos, basta con el CSS.
Nota sobre versiones: Las versiones cambian con el tiempo. Los ejemplos suelen usar la 5.3.x; conviene revisar en getbootstrap.com cuál es la versión vigente y copiar el enlace actualizado directamente desde su documentación oficial.
